# Deploying JobTrackr to Render (≈10 minutes)

The project is production-ready. These are the steps only you can do, because they
use **your** accounts. Render's free tier includes HTTPS automatically.

> Why you and not an automated step: deploying means creating an account,
> agreeing to the host's terms, and authorizing it to pull your code. Those are
> yours to approve. Everything else (config, security, build) is already done.

---

## 1. Put the code on GitHub (one time)

Render deploys from a Git repo.

```bash
cd jobtrackr
git init
git add .
git commit -m "JobTrackr: initial deploy"
# Create an empty repo on github.com first, then:
git remote add origin https://github.com/YOUR_USERNAME/jobtrackr.git
git branch -M main
git push -u origin main
```

`.env`, `db.sqlite3`, and build artifacts are already git-ignored, so no secrets
get pushed.

## 2. Create the services on Render

1. Sign up / log in at <https://render.com> (you can sign in with GitHub).
2. **New → Blueprint**.
3. Connect your `jobtrackr` GitHub repo. Render reads `render.yaml` and shows a
   plan: one **web service** + one **Postgres database**.
4. Click **Apply**. Render builds the app, runs migrations, and gives you a URL
   like `https://jobtrackr.onrender.com`.

`SECRET_KEY` is generated for you, `DATABASE_URL` is wired automatically, and
`DEBUG` is already `False`. HTTPS is on by default.

## 3. Add your secret keys

In the Render dashboard → your web service → **Environment**, fill in the values
marked `sync: false` in `render.yaml`:

| Key | Where to get it |
| --- | --- |
| `OPENAI_API_KEY` | platform.openai.com/api-keys |
| `PAYSTACK_SECRET_KEY` | Paystack dashboard → Settings → API Keys |
| `PAYSTACK_PUBLIC_KEY` | same page |
| `PAYSTACK_PLAN_CODE_NGN` | Paystack → Plans (create a ₦1,500 monthly plan) |
| `PAYSTACK_PLAN_CODE_USD` | Paystack → Plans (create a $5 monthly plan) |

Click **Save changes** — Render redeploys automatically.

## 4. Create your admin login

In the Render dashboard → your service → **Shell**:

```bash
python manage.py createsuperuser
```

Now you can log into `https://YOUR-APP.onrender.com/admin/`.

## 5. Point Paystack's webhook at the live app

Paystack dashboard → Settings → API Keys & Webhooks → **Webhook URL**:

```
https://YOUR-APP.onrender.com/billing/webhook/
```

This is how renewals and cancellations stay in sync. It's signature-verified.

## Security checklist (already handled for you)

- ✅ HTTPS enforced (`SECURE_SSL_REDIRECT`), HSTS enabled
- ✅ Secure, HTTP-only session & CSRF cookies
- ✅ `DEBUG=False` in production
- ✅ Strong `SECRET_KEY` generated by Render, never in the repo
- ✅ Secrets (OpenAI, Paystack) stored as Render env vars, not in code
- ✅ Passwords hashed (Django auth); each user sees only their own data
- ✅ Paystack webhook verifies the signature before trusting any event
- ✅ Clickjacking protection (`X_FRAME_OPTIONS = DENY`)
